## 🚀 Featured Projects

### 🤖 [NHL Hockey Data Collector — Automation Anywhere 360](https://github.com/GregoryCarberry/nhl-hockey-data-collector)

An RPA portfolio project that extracts NHL team-season statistics from a paginated website and consolidates the results into CSV.

- Built using Automation Anywhere 360 Community Edition.
- Handles pagination and detects repeated pages.
- Includes data consolidation and duplicate checking.
- A documented full test successfully exported **582 data records** across 24 unique pages.
- Includes an importable bot export, source files and a changelog.

**Focus:** RPA, data extraction, workflow design, troubleshooting.

### 🔌 [TCP Smart Plug Local Control](https://github.com/GregoryCarberry/tcp-smart-local-control)

A project that started with a simple question: could I control two existing TCP Smart Wi-Fi plugs locally through Home Assistant without resetting or re-pairing them?

It turned into an investigation involving network traffic, Android tooling, Python and the Tuya device protocol.

- Investigated device communication and local authentication.
- Recovered the information required for local control.
- Integrated both plugs with Home Assistant.
- Investigated device datapoints, including countdown timer behaviour.
- Documented successful tests, unsuccessful approaches and remaining limitations.

**Result:** Both plugs working with local Home Assistant commands while retaining their original app pairing. Complete internet-isolation testing remains outstanding.

**Focus:** Python, networking, troubleshooting, IoT, Home Assistant.

### ☁️ [AWS Well-Architected Static Site](https://github.com/GregoryCarberry/well-architected-static-site)

A reproducible AWS static website hosting project built using Terraform and GitHub Actions, with an emphasis on security, operational practices and cost awareness.

- Private S3 origin with CloudFront Origin Access Control.
- AWS WAF, ACM certificates and Route 53 DNS.
- Modular Terraform infrastructure.
- GitHub Actions deployment using OIDC authentication.
- Regional AWS requirements, security controls and cost considerations.

**Focus:** AWS, Terraform, Infrastructure as Code, CI/CD, cloud security.
